window11執行python 發生cp950的編碼問題

✅ 解決方案：從「系統層級」修改預設編碼為 UTF-8（不需每次程式碼加參數）
方式一：變更 Windows 預設編碼為 UTF-8
這是最推薦的方式，能永久性解決 Python 和其他程式中出現的 CP950 錯誤。

🔧 步驟如下：
打開「控制台」 → 「時鐘與地區」 → 「區域」

切到「系統管理」分頁

點選「變更系統地區設定（Change system locale）」

✅ 勾選「Beta: 使用 Unicode UTF-8 提供全球語言支援」

點「確定」後重新啟動系統

🟡 這樣就能讓 Python 的預設編碼變成 UTF-8，不再使用 CP950，所有無法處理的字元問題都會大幅減少。
